Access Control System

A Java-based access control system that manages user permissions for different resources based on their roles and security levels.

The project demonstrates object-oriented programming, access control, capabilities, and unit testing with JUnit 5.

Features

* Role-based access control for guests, students, staff, and administrators
* Read and write permissions
* Public, internal, and confidential security levels
* Access logging
* JUnit 5 tests covering allowed and denied access, invalid input, and capabilities

Requirements

* Java 17+
* Maven

#How to Run

Clone the repository and navigate into the project:

git clone https://github.com/sazzzz23/Access-control-system.git
cd Access-control-system

#Run the tests:

mvn clean test

#To compile the project:

mvn clean package

The project is primarily a Java access-control implementation with JUnit tests rather than a standalone GUI application.
